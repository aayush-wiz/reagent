Reagent is a research agent. Ask it a question and it grounds itself in real literature, holds several rival hypotheses, runs experiments to tell them apart, and hands back a cited answer. This is the reference for **how that works** — the whole method end to end, and the numeric algorithms underneath it.

## A loop, not a line

A linear pipeline — guess one hypothesis, run one analysis, write it up — can only ever *confirm* what you already guessed. Reagent instead runs an **iterative Strong-Inference tournament**: it holds several rival hypotheses, makes them compete, kills some with evidence, and re-enters earlier steps as results arrive. Everything in these docs serves that loop, chosen from the live state of the research rather than a fixed schedule.
